# IIDX INFINITAS SCORE VIEWER

公式スコアCSVをローカルで表示する、GitHub Pages対応の非公式Webビューアです。チョコミント系ダークテーマ、PCテーブル／スマホカード表示。


## CSVの読み込み

- INFINITAS公式サイトからダウンロードしたSP・DPのCSVを「CSVを読み込む」から選択。2ファイル同時選択可。
- ファイル名に `_sp_` / `_dp_` が含まれていれば自動判定。それ以外は読み込み時にモードを入力。
- 同じモードのCSVを再読み込みすると、そのモードの保存データを置き換えます。
- ファイルは外部サーバーに送信しません。ブラウザ内で処理し、IndexedDBに保存します。
- ブラウザの保存領域を消去した場合、別のブラウザや端末からアクセスした場合は、CSVを再度読み込んでください。

## 主な機能

- SP / DP切替、曲名・アーティスト・バージョン検索
- 難易度、クリアランプ、バージョン、プレー状況の複合フィルタ
- EXスコア、ミスカウント、プレー回数、各日時等のソート
- PC版の列表示切替、譜面詳細、50件ずつのページ送り
- 絞り込み結果のCSV出力（Excel用UTF-8 BOM付き）
- CSVの1曲1行を1難易度1行に展開

## 注意

- 公式CSVに譜面レベルや最大ノーツ数がないため、現バージョンでは表示しません。後日マスターを結合する設計に拡張できます。
- CSV内の `NO PLAY` は譜面未収録を意味するとは限りません。未プレーの数は未収録枠を含む可能性があります。
- 「登録曲数」は現在のモードの曲名とバージョンの組み合わせの数です。
- このZIPには個人のスコアCSVを同梱していません。
- CSVは元の形式に沿って読み込みます。将来公式のCSV列名が変わった場合、対応が必要です。
- コナミ公式とは関係ありません。
